# TextSpeedReader

TextSpeedReader 是一款基於 .NET Windows Forms 開發的多功能文字閱讀與編輯器，旨在提供流暢的檔案瀏覽與多樣化的文字處理工具。

## 專案用途

本工具主要用於快速開啟、閱讀並編輯各類文字檔案。除了基本的編輯功能外，它還整合了檔案管理、編碼修正以及繁簡轉換等進階功能，特別適合開發者、文字工作者或需要處理不同編碼檔案的使用者。

## 主要功能

### 檔案瀏覽與管理
- **樹狀目錄 + 檔案清單**：TreeView 顯示目錄結構（惰性載入），ListView 顯示當前目錄內的檔案。
- **多格式支援**：可在編輯器中開啟 `.txt`, `.cs`, `.yaml`, `.js`, `.py`, `.md`, `.css`, `.json`；以 WebBrowser 預覽 `.html`, `.htm`。
- **拖曳開啟**：支援從 Windows 檔案總管拖曳檔案或資料夾至程式視窗。
- **檔案拖曳操作**：
  - 拖曳 ListView 中的檔案至 TreeView 目錄：按住 **Ctrl** 為複製，放開為搬移
  - 支援多選項目同時拖曳
  - 搬移後自動從 ListView 移除已搬走項目
- **資料夾操作**：新增子目錄、刪除（移至資源回收筒）、重新命名，亂碼修正，繁簡轉換。
- **檔案操作**：刪除（移至資源回收筒）、重新命名，單檔與多檔批次更名皆支援，繁簡轉換。
- **檔名搜尋**：在 ListView 中以關鍵字搜尋並選取符合的檔案。
- **在多個檔案中搜尋文字** (Ctrl+Shift+F)：對目前 ListView 顯示的所有文字檔案進行全文搜尋，以 TreeView 階層顯示「檔案 → 命中行」，點擊結果即開啟該檔案並反白比對字。支援半/全形視為相同、大小寫切換；命中字以黃底紅字粗體凸顯；大檔案（>5MB）與大量命中（每檔 50 筆 / +100 批次）會彈窗確認，避免效能卡頓。

### 文字編輯
- **RichTextBox 編輯器**：支援字型選擇、字體大小調整（預設尺寸清單）、自動換行切換。
- **尋找 / 取代**：
  - 支援「區分大小寫」與「全字匹配」
  - 「尋找下一個」與「尋找上一個」雙向搜尋，均支援循環查找
- **拖曳選取文字**：可拖曳外部文字直接插入。

### 文字處理工具
- **移除多餘斷行**：合併段落內的單行換行，保留雙換行（段落分隔）。
  - 進階版：可保留以句號、問號、驚嘆號結尾的行換行。
- **自動移除多餘的斷行**：自動移除多餘的斷行，跳過行尾句點或驚嘆號。每行行尾的半形空格、TAB、全形空白（U+3000）會在判定前自動剝除，避免被尾端空白影響判定。
- **半形標點符號轉全形**：將 `, . ! ? : ; ( )` 等一般文章標點批次轉成對應的中文全形標點；可作用於選取範圍或全文。
- **確保段落空白行**：讓每對非空行之間恰好有一個空白行。
- **移除空白行**：移除所有空白行，使各行緊密排列。
- **移除行首/尾空白**：清除半形空格、TAB、全形空格。
- **行首加縮排**：為每個非空行加上指定數量的空白字元；空白數量與「半形/全形空白」皆可在「選項」視窗中調整（預設全形空白 U+3000）。
- **行尾補句號**：對未以標點結尾的行自動補上全形句號「。」。
- **行排序**：正向 / 反向排序，支援保留空白行的分段排序模式。
- **依判定字串拆行 / 合行**：可在設定中指定「新行開頭判定字串」與「新行結尾判定字串」，對文字進行段落切分或合併。
- **插入行首/尾標記**：為每個非空行加上設定中指定的開頭與結尾字串。
- **行號標記插入**：
  - 在選取範圍的每行行首插入「AnnotationBegin + 單位序號 + AnnotationEnd」
  - 編號為四位數零填補格式（例：`/*0001*/`）
  - 支援大括號 `{...}` 區塊：`{` 必須行首、`}` 必須行尾，支援巢狀，整個區塊視為一個單位，只佔一個編號
  - 已有標記時自動更新序號
- **超過指定字數自動分行**：彈窗詢問每行字數上限（預設 120），對超出長度的行於下一個句號/驚嘆號/問號處自動斷行。

### 編碼修正
- **智慧編碼修正（ReCodeText）**：將目前文字以「錯誤編碼 → 正確編碼」重新解碼，預覽多種組合後選取。支援可選同步執行簡→繁轉換。
- **檔名編碼修正（ReCodeFileName）**：修正 ListView 中選取的檔案或目錄名稱的編碼錯誤。
- **目錄名稱編碼修正（ReCodeFolderName）**：修正 TreeView 中選取目錄的名稱編碼。
- **批量編碼修正（ReCodeFullFoldersFilesName）**：遞迴修正指定目錄下所有檔案與子目錄的名稱編碼。
- 支援的編碼組合：UTF-8、UTF-8-BOM、GBK（936）、Big5（950）、GB18030（54936）、Unicode（UTF-16 LE）。

### 繁簡轉換
- **文字內容轉換**：將目前開啟的 `.txt` / `.json` 轉換為簡體並另存（檔名加 `_簡體1`）。
- **批次轉繁/轉簡**：對 ListView 中選取的多個 `.txt` / `.json` 批次轉換並另存。
- **檔名繁簡轉換**：將 ListView 中選取的檔案或目錄名稱以 OpenCCNET 轉為繁體。
- **目錄名稱繁簡轉換**：將 TreeView 中選取目錄的名稱轉為繁體。
- 使用 OpenCCNET 函式庫（`HantToHans` / `HansToTW`）。

### 儲存功能
- **覆蓋儲存**：以原始編碼覆蓋目前檔案。
- **另存新檔**：以 UTF-8-BOM 儲存，支援多種副檔名。
- **選取內容另存**：將目前選取的文字另存為新檔，自動產生不重複的三位數序號檔名。
- **整篇分割儲存**：將整篇文字以每份 3,000 字切割，批次存為多個序號檔案。

### HTML 瀏覽（WebBrowser 模式）
- 自動偵測 HTML 檔案編碼（GB2312/GBK → UTF-8），必要時產生臨時檔案確保正確顯示。
- 可調整頁面縮放比例（預設縮放清單）。
- 複製 WebBrowser 選取文字並轉換為繁體/簡體後儲存為 `.txt`。

### AI 分析文章（地端 Ollama 整合）
- **「AI分析文章」按鈕**：開啟獨立、非模態的「AI分析文章選項」視窗（不阻擋主介面操作，可同時繼續瀏覽/編輯其他檔案），對 ListView 目前顯示的文字檔案批次進行 AI 分析。
- **溝通方式**：以標準 `HttpClient` 直接呼叫本機 Ollama REST API（`GET /api/tags`、`POST /api/generate`），不需任何額外套件或後台服務。
  - 位址解析優先順序：Windows 系統變數 `OLLAMA_HOST`（Process → User → Machine）→ 若未設定或連線失敗，自動退回 `http://127.0.0.1:11434`。
- **模型選擇**：下拉選單即時列出 Ollama 已下載的模型，可「重新整理」。
- **AI 參數預設表**：內建 10 組（依 `num_ctx` 8192/16384/32768/65536 與溫度組合）常用取樣參數（temperature、num_predict、num_ctx、repeat_penalty、top_k、top_p）供下拉選擇。
- **文章類型提示詞（Prompt）**：掃描 `Prompt\*.md` 作為分析提示詞範本（內建「經典情色文學的學術分析」），可透過「編輯」按鈕開啟內建的 Markdown 編輯彈窗（左側即時預覽、右側編輯，90% 螢幕尺寸），支援「另存新檔」建立新的文章類型。
  - 編輯時輸入焦點穩定停留在編輯欄（不會被預覽框搶走游標），且預覽會自動捲動同步到目前編輯的區塊位置。
- **使用者指令**：可額外輸入指令，與文章類型提示詞、文章本文一併組成最終提示詞送給模型。
- **檔案勾選列表**：右側列出所有候選檔案並可個別勾選（預設全選），搭配「全選 / 清除選取 / 反選」按鈕，方便檔案較多時分批處理。
- **思考模式（think）開關**：預設**不勾選**（提示文字「開啟思考模式會增長分析時間」，送出 `think:false` 跳過推理模型的思考階段以加速）；勾選後會即時顯示模型的思考過程（thinking token，獨立段落標示），但會明顯增加分析時間。
- **執行紀錄（LOG）**：
  - 採緩衝區 + 定時（120ms）刷新機制寫入，避免逐字更新造成畫面閃爍與 CPU 佔用過高。
  - AI 回傳內容正規化換行後顯示，避免全部擠成一行。
  - 送出請求前，**完整輸出當次提示詞全文**（文章類型範本 + 使用者指令 + 待分析文章內容，逐字顯示），方便核對實際送給模型的內容。
  - 顯示呼叫參數、首個 token 回應時間，以及 Ollama 伺服器端計時分解（模型載入 / prompt 評估 prefill / 生成 eval 各階段秒數與 tokens/s），並顯示模型目前 GPU/CPU 載入位置診斷（`/api/ps`），方便排查效能瓶頸。
- **結果儲存**：每篇分析完成後存為「原檔名_AI分析.txt」（UTF-8 無 BOM），檔名重複時自動加註 `_01`、`_02`…序號。

### 閱讀紀錄
- 自動儲存最近閱讀的檔案路徑與閱讀字元位置，方便續讀。
- 支援「自動開啟上次目錄」。
- 最近目錄與最近檔案各保留最多 10 筆（MRU 順序）。

## 技術架構

| 項目 | 內容 |
|------|------|
| 框架 | .NET Windows Forms |
| 語言 | C# |
| 主要表單 | `FormTextSpeedReader`（分拆為多個 partial class 檔案） |
| 設定儲存 | INI 格式，`.\TextSpeedReader_Settings.ini` |
| 編碼偵測 | UDE（Universal Charset Detector）+ BOM 判斷 |
| 繁簡轉換 | OpenCCNET |
| 檔案刪除 | `Microsoft.VisualBasic.FileIO`（使用資源回收筒） |
| AI 分析 | 本機 Ollama REST API（`HttpClient` + `System.Text.Json`，NDJSON 流式解析） |
