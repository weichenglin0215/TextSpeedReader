# 翻譯日文歌詞
將日文歌詞翻譯成 羅馬拼音 + 繁體中文 + 繁體中文(依照音節控制字數)。

## 目標
讓日文歌詞變成可以哼唱的繁體中文歌詞，兩者的音節數必須相同。

## 輸出格式
- 日文與繁體中文的歌曲名稱。
- 日文原稿。
- 羅馬拼音，每一行的最後加上音節數。
- 繁體中文，將日文翻譯成意境深遠文字優美的繁體中文。
- 繁體中文(依照音節控制字數)，依照音節數量來翻譯(編寫)成相同字數的繁體中文歌詞。
